# FitLog

FitLog is a modern fitness and workout planning web application built with Next.js. It allows users to explore exercises, view exercise details, create a daily workout plan, save exercises for later, and track completed workouts.

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Hot Toast
- React Context API

## ✨ Key Features

### 1. Exercise Library

Users can browse a collection of exercises loaded from an external API. Each exercise card displays important information such as exercise name, equipment, duration, calories, difficulty, and rating.

### 2. Exercise Details

Users can click any exercise to view its detailed information, including description, instructions, sets, repetitions, duration, calories, and equipment.

### 3. Today's Workout Plan

Users can add exercises to **Today's Plan** and remove them when they are no longer needed. Exercises already added to the plan cannot be added again.

### 4. Save Exercises for Later

Users can save exercises for future workouts. Saved exercises can be added to Today's Plan whenever needed.

### 5. Workout Progress & Live Metrics

Users can mark exercises as completed and view live workout statistics, including:

- Total Exercises
- Total Minutes
- Total Calories

The metrics automatically update when exercises are added or removed from Today's Plan.
